# SF-AM-0001 — Manufacturing socket ownership

**Version:** 1.1.0  
**Status:** EFFECTIVE  
**Machine-readable contract:** `skyforge.manufacturing-axes.v1`

## Rule 5 — Socket ownership

Mesh Foundry may emit approved or candidate three-dimensional sockets in normalized mesh
coordinates. These are source candidates only and are not runtime socket authority.

Sprite Foundry owns projection of approved three-dimensional sockets into every authored sprite
frame. Sprite Foundry stores the resulting per-frame two-dimensional sockets in the Gameplay Sprite
Package together with the frame and calibration identity used for projection.

Gameplay integration validates and consumes the per-frame two-dimensional sockets. It may reject
invalid or incompatible socket data, but it does not own projection and must not reach back into Mesh
Foundry during runtime integration.

The independent Import Probe verifies that VMP manufacturing-axis ownership exactly matches the
versioned enumeration in `contracts/vmp/v1/schemas/manufacturing_axes.schema.json`.

This effective document incorporates and supersedes the v0.7.0 amendment wrapper previously shipped
as `SF-AM-0001_Rule_5_Socket_Ownership_Amendment.md`.
