# v0.8.1 No-Spend Test Plan

Tests use injected fake transports and deterministic fixture GLBs. Network access is not required. The suite covers malformed bundles, unsupported profiles, post-approval mutation, traversal/symlinks, stale authorization, insufficient budget, disabled paid mode, CI/network kill switches, missing keys, duplicate and ambiguous submission, documented HTTP failures, polling/download failures, corrupt GLBs, illegal lifecycle transitions, orientation ambiguity, manifest mutation, raw-byte preservation, default-route isolation, and secret redaction.

Acceptance requires Producer and Import Probe Ruff/tests, both source bindings, the historical probe comparison, deterministic evidence rerun, and GitHub Actions. Fixture outputs must say they are fixtures and must never be described as live Meshy results.
