# v0.8.1 Authority-Bundle Gate Handoff

PR #6 and MBS-CR-0027 establish only the secure preauthorization architecture. No live provider task is authorized.

No approved same-craft top/front/right authority bundle currently exists. Test fixtures and prior single-view evidence cannot be used. The first recommended smoke asset is `enemy_gunship`.

The required authority bundle must contain three independently stored images in this order:

1. `top`
2. `front`
3. `right`

All three images must depict the same exact craft with consistent proportions, cockpit, engine housings, weapons, palette, markings, and scale.

The bound bundle must include:

- source provenance;
- image SHA-256 hashes;
- dimensions and image modes;
- profile;
- contact sheet;
- bundle digest; and
- explicit human approval.

Do not enter a Meshy API key or purchase or consume credits until the exact bundle has been visually approved and bound. Immediately before any final live authorization, re-verify the Meshy endpoint and request parameters, `meshy-6` availability, current credit cost, retention rules, initial artifact host, DNS/address policy, and redirect policy again under MBS-183.

Completing this bundle gate does not itself authorize submission, polling, artifact download, paid work, or visual testing of provider output. Those actions require separate explicit authorization.
