2. Double-click `run_pilot_ui.command`.
3. Confirm the launcher reports the localhost URL `http://127.0.0.1:5180` and its local log location.
4. Open `http://127.0.0.1:5180` in a browser if it does not open automatically.
5. Confirm the page is titled **SkyForge Mesh Builder — v0.8.1 Multiview Meshy Pilot** and displays **EXPERIMENTAL PILOT — SEPARATE FROM v0.7.1 PRODUCTION ROUTE**.
