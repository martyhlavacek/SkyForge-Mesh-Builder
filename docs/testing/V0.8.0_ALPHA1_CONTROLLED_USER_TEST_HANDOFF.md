# v0.8.0 Alpha 1 Controlled User-Test Handoff

MBS-CR-0025 accepted exact candidate `c5531e37bd2a379e4714e9f4e9904ed149b652c7` for controlled visual/user testing. This handoff prepares that testing for Marty; it does not record or perform the test.

## Review scope

Compare the Alpha 1 evidence with the unchanged v0.7.1 base shell and record observations for:

- the approved gunship and interceptor overall;
- cockpit-volume readability;
- weapon-volume readability;
- gunship belly readability;
- whether every component appears attached, with no visible floating;
- gunship engine capsules, especially whether they read as engine housings or merely as inboard bulges;
- visible seams or z-fighting;
- the visual difference from the unchanged v0.7.1 base shell.

Use the accepted evidence package bound by SHA-256 `a49869762bcbb1811694122c9d64af2eee554dd290ab846fbcd272b1b1fa7a3f`. Record the exact commit and evidence digest with any test result.

- MBS-152 remains the weakest visual area.

- No paid-provider testing is authorized; MBS-136 remains open against a real provider.
