# v0.8.1 Shared Authority Geometry Source Plan

## Status: LATER / CONTINGENCY

MBS-195 remains open. The rejected bundle identified by digest `c624051f4b18121058b402ff439f345c391ae4aa721a7945961d72590581117f` is preserved as evidence and is not suitable for provider preauthorization. This document records a contingency architecture only. It authorizes no scaffold implementation and no live provider action.

Independent image-model generations are no longer an acceptable method for creating separate FRONT and RIGHT geometric authority views. Image generation may remain useful for beauty or concept art, design-language reference, and optional non-authoritative appearance reference. It may not independently establish the geometry of multiple authority views.

## Preferred next empirical direction: Track S

Track S is the preferred next empirical direction. It begins with one approved three-quarter beauty reference and uses the existing reviewed Meshy multi-image endpoint with `N=1`. The approved TOP authority is an independent validation target, not a second reconstruction input for the first experiment. Any second-view experiment requires separate authorization and must be justified by evidence from the first task.

## Contingency: Shared Authority Geometry Scaffold

The Shared Authority Geometry Scaffold may be reconsidered only if provider evidence demonstrates a need for coherent multiview reconstruction or deterministic multiview validation geometry. If authorized in a later task, it would create one coarse 3D geometry source and derive TOP, FRONT, and RIGHT authority images from that exact source using Blender orthographic cameras. The scaffold would not be the final production mesh; it would exist solely to provide coherent multiview reconstruction authority.

Requirements:

1. TOP remains the primary planform and identity anchor.
2. The scaffold represents separate major volumes: central fuselage, cockpit volume, left and right nacelles, dorsal weapon or equipment volume, forward gun volumes, and other silhouette-critical major components.
3. Beauty artwork is visual reference for vertical massing only and is not a geometric authority image.
4. A human operator may tune bounded height and profile parameters.
5. All three authority images are Blender renders from one geometry object or object set.
6. TOP, FRONT, and RIGHT cameras are exact orthographic cameras.
7. Camera transforms, orthographic scale, object origin, and render resolution are persisted in evidence.
8. The TOP render is compared back to the approved TOP authority using the project's existing silhouette-comparison discipline.
9. FRONT and RIGHT are derived from the same physical scaffold, preventing independent W/L/H proportion drift.
10. The MBS-196 deterministic cross-view consistency gate remains mandatory for scaffold-generated views.
11. No stochastic image generation occurs between scaffold rendering and authority-bundle import.

Any later scaffold experiment must retain human approval, exact file and bundle hashing, append-only lifecycle controls, stale-contract refusal, and all no-spend/provider boundaries. A new coherent bundle must pass the measured gate and receive human approval before MBS-195 can be considered for closure. If the multiview route is abandoned rather than repaired, MBS-195 may become `SUPERSEDED BY SCOPE`; it must not be marked CLOSED on that basis.

This document does not implement Track S, authorize a second view, authorize the scaffold, or authorize any live provider operation.
