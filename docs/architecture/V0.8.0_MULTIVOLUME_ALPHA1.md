# v0.8.0 Multivolume Alpha 1 Architecture

Alpha 1 is an offline, opt-in experiment alongside the unchanged v0.7.1 authority-mesh generator. It is not imported by the server, UI, provider registry, VMP exporter, or Import Probe.

The experiment first invokes `generate_authority_mesh()` in an external evidence directory. Its passing GLB becomes the exact planform-bearing `base_shell`. A schema-validated profile recipe then places deterministic closed `trimesh` primitives from the measured authority length and the occupied span of each selected authority row. RGB is not read for placement or dimensions; it is used only for planar texture projection.

Each semantic component remains an independently watertight shell. Components may penetrate the base by a positive, recorded depth, but Alpha 1 deliberately avoids boolean union and new geometry dependencies. The assembly is exported with the established target-XYZ to glTF-X/Z/-Y encoding and independently reloaded to audit component count, names, bounds, topology, and semantic registry.

Supported recipes are `enemy_gunship` and `enemy_interceptor`. Unsupported profiles fail closed. Outputs include textured and component-coloured GLBs, OBJ, reports, registries, five diagnostic views, a planform overlay, cross-sections, a legacy comparison sheet, and SHA-256 manifests.

This architecture only candidate-addresses MBS-151 through MBS-154. It does not close findings, change the accepted generator, or authorize VMP/UI/provider integration or user testing.
