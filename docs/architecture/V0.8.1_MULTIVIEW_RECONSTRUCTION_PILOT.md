# v0.8.1 Multiview Reconstruction Pilot Architecture

The pilot is an isolated, opt-in, provider-backed experiment. It does not alter the accepted deterministic v0.7.1 route, and `geometry_v2` remains an inactive negative experiment following its separate technical acceptance and human visual rejection.

`MultiviewAuthorityBundleV1` binds exactly three independently stored authority images in `top`, `front`, `right` order. It records hashes and image metadata, rejects traversal and symlinks, supports only gunship and interceptor profiles, and invalidates approval when content changes.

The provider-neutral boundary exposes cost estimation, request preparation, task submission, polling, artifact download, response handling, and evidence redaction. The only adapter is Meshy Multi-Image to 3D. Dry-run preparation is the only default entry point.

A POST requires local paid enablement, an exact approved and confirmed bundle digest, a sufficient credit cap, a secure key, non-CI execution, the process-level network kill switch to be off, and proof no task or ambiguous prior attempt exists. POST is never retried automatically. Polling uses GET only. The same provider-layer network guard protects task retrieval, polling, single-artifact download, and bulk download.

Artifact downloads require HTTPS, no credentials or IP literals, the default HTTPS port, and an exact hostname match in a versioned Meshy artifact-host contract. Redirect targets and final response URLs are revalidated. The production host set is intentionally empty until official Meshy artifact hosts are re-verified immediately before a separately authorized live smoke task; offline tests inject fixture-only hosts.

Raw provider GLB bytes are retained unchanged. A separate review copy is selected by deterministic search over all 24 proper axis-aligned rotations using top/front/right silhouette scores. Ties fail closed. Scale and origin normalization happen only on the canonical review copy. Silhouette scores constrain orientation but are not semantic-quality proof; human review remains authoritative.

No paid call, live provider result, Alpha 2 geometry, boolean-union rescue, provider comparison, or default-route integration is part of this candidate.
