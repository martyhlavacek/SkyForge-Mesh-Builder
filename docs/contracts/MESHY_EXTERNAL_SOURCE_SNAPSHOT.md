# External Source Snapshot

Checked against official Meshy documentation on 3 August 2026.

Facts used:

- Multi-Image to 3D accepts 1–4 images of the same object from different angles.
- Inputs may be public URLs or base64 Data URIs.
- Endpoint: `/openapi/v1/multi-image-to-3d`.
- Meshy-6 pricing is currently listed as 20 credits without texture, 30 with texture, and 35 with 8K texture.
- Non-Enterprise API assets are documented as retained for a maximum of three days.
- Authentication uses a Bearer API key.
- 400, 401, 402, and 429 are documented failure classes.

Re-verify before any live task because provider contracts and prices may change.
